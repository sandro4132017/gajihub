========================================================================
FOLDER ASSET GAMBAR (public/images/)
========================================================================

Folder ini digunakan untuk menyimpan seluruh aset gambar statis aplikasi Gajihub.

Untuk Aset SPTJM / Dokumen:
- Logo Garuda / Kemnaker : public/images/logo-kemnaker.png  atau  public/images/logo-garuda.png
- Kop Surat Lengkap      : public/images/kop-kemnaker.png   atau  public/images/kop-sptjm.png

Format yang disarankan:
- PNG transparan resolusi tinggi (300 dpi atau minimal 300x300 px) untuk logo.
- PNG / JPG lebar 1200+ px untuk kop surat utuh.
